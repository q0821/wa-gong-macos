## 決策與理由

- 保留 SwiftData，採新增可選欄位及相容預設，因為既有詞庫、歷史與同步需要保持相容；不重建資料庫、不回填舊原稿。
- 正確詞加入即啟用，使用一份工作快照貫穿辨識、整理與固定替換；否決每階段讀庫，避免處理途中設定改變。
- 能力與預算由共同政策決定，未知模型保守不送。未採用、截斷、詞庫不可讀都可見，不冒充已使用。
- 固定替換只在原始範圍一次組裝，拒絕跨階段鏈與循環；既有衝突規則保留資料但停用當次替換，避免無聲改壞輸出。
- 最終固定保護適用文字輸入整理；助理回答與翻譯不強制替換產出。原始辨識保存在既有歷史生命週期內，取消即清除；診斷只存狀態與數量。
- 正確詞以有界 JSON 資料送入文字請求，不插入 system 指令。Wa-Gong Refine 維持既有模型輸入契約並明示不支援詞彙提示，避免未驗證的小模型提示改變。

## 實作狀態

1. 已實作核心快照、能力政策及非級聯替換，並加入行為測試。
2. 已串接檔案、即時、fallback、匯入、重新轉錄及整理，使用共同快照與診斷。Groq 補上 `prompt`，Deepgram 檔案路徑補上 `keyterm`。
3. 已實作每詞啟用、輸入驗證、備份相容與歷史原稿畫面。舊歷史明示原稿未記錄，不用整理後文字冒充。
4. 已執行隔離測試及未簽署建置。下方另列真人、跨 App 與 Provider 驗收限制，這些項目仍阻擋完整功能驗收。

詞彙狀態表示請求是否附帶提示，不代表模型確實採用了每個詞，也不代表辨識正確率已提升。診斷只記數量、路徑與狀態；原稿沿用 macOS 既有本機歷史儲存與刪除生命週期，不送往 CloudKit。

Whisper 的 224 bytes 是本專案採用的保守詞表預算，不是服務文件的 token 上限。未知模型不推定支援；加入新模型時必須一併確認 adapter 與政策。自訂提示可能翻譯，因此只有內建同語言整理模式與 Refine 執行整理後固定替換，助理回答與自訂改寫不強制替換。
