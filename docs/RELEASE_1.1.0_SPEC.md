## 目標與範圍

將自 v1.0.1 公開版以來的自訂詞彙、本機 TEA、模型篩選及鍵盤診斷變更整理為 1.1.0 候選版，讓公開下載版、開發來源與本機安裝版可明確區分。

- App、測試 target 與 XPC 的三段式版本由 1.0.1 升為 1.1.0，build number 由 2 升為 3。沿用現有 Bundle ID、Team、簽署與資料位置。
- README 說明公開版仍為 1.0.1、開發候選版為 1.1.0；補詞彙及 TEA 使用方式、正確模型歸屬與已知限制。
- CHANGELOG 新增 1.1.0「尚未發布」，保留 1.0.1 以下的歷史版本原文；更新說明新增 release-notes/1.1.0.html。
- BUILDING 修正建置與本機 Release／公開發版的區分；handoff 新增本輪入口與安裝證據。
- 使用一般 Release 重新建置並安裝至 /Applications/Wa-Gong.app，保留前版備份，核對版號、簽章、來源、helper 與執行程序。

## 不處理項目

- 不合併、不提交或推送 main，不建立 Tag、PR 或 GitHub Release，不公證，不修改 appcast.xml 的公開更新 feed。
- 不修復雲端整理、鍵盤或詞彙行為，不新增 App 版本紀錄介面。現有程式碼未有該畫面，這輪先同步既有文件與版本欄位，介面新增需另列規格。
- 不讀取私人詞庫、錄音或 Keychain 值，不做真實雲端請求或資料庫 migration，不刪除前版與模型。

## 內容與狀態規則

- 更新說明僅描述已接入行為，不把測試或啟動成功寫成真實辨識品質、跨 App 或 VoiceOver 已驗收。
- README 的公開下載連結與 released badge 保持指向現有 1.0.1，1.1.0 顯示為尚未發布，不連向不存在的資產。
- 詞彙選取只在明確快捷動作時使用 AX，無讀取能力時保留手動輸入；歷史修正保留 rawTranscript，固定替換須另勾選。
- TEA 為第三方模型，由 App 管理 native helper 與模型匯入／下載，不隨 App 內嵌權重。使用雲端整理仍會傳送轉錄文字及適用詞彙。
- 2026-10-22 使用者決定 Gemini 逾時與 Claude 額外說明先暫停追蹤，不再列為本輪發版阻擋或修復工作。歷史證據保留於本機 Issue，不宣稱已修復；Gemini 外部伺服器短暫異常僅為使用者推測，Claude 後續正常為使用者回報。
- 本機裝有 1.1.0 不代表 GitHub 已發布。候選原始碼若未提交，metadata 必須記錄 dirty 與完整 source fingerprint，不假裝 base SHA 已包含新版本設定。

## 決策與理由

- 選擇 1.1.0，否決繼續沿用 1.0.1，因為包含多項使用者可感知的新功能；否決僅 1.0.2，因為並非只有修錯。
- 選擇先準備文件與本機候選產物，否決立即更新公開 feed，因為新資產、公證及實機證據尚未齊全。
- 選擇保留原有釋出歷史，否決改寫 1.0.1 內容，因為原公開產物必須仍可對應既有更新說明。
- 依使用者最新決定暫停上述兩項追蹤，否決繼續將其當作本輪必修阻擋，因為使用者認為 Gemini 可能是暫時外部異常，且回報 Claude 後續未再遇到問題。否決改標「已修復」，因為本輪沒有修碼或取得根因／修復驗證。
