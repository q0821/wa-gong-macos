## 問題與影響

修正前介面將第三方 `VoiceInk Refine V1` 顯示成 `Wa-Gong Refine V1`，Provider 顯示為 `Wa-Gong Refine`，但實際模型來源仍為 `beingpax/VoiceInk-Refine-V1`。冠上本產品品牌會讓使用者誤以為模型由 Wa-Gong 開發，混淆第三方模型來源與歸屬。此問題涉及來源透明與使用者信任，不應視為單純的文案偏好。

這不是本次規劃的 Ollama `qwen3.5:9b`，不得以改名或設定別名讓使用者誤以為已切換模型。

已確認的是來源與顯示名稱不一致；本紀錄未就授權違規或法律責任作出判定。

## 已確認證據

- `VoiceInk/Services/AIEnhancement/VoiceInkRefineService.swift`：`providerName = "Wa-Gong Refine"`、`modelName = "Wa-Gong Refine V1"`、`repositoryID = "beingpax/VoiceInk-Refine-V1"`。
- `VoiceInk/Services/AIEnhancement/AIService.swift`：Provider 顯示名稱與持久化識別相連，並存在舊名稱相容處理。修正須保留既有設定的可讀性，不可只機械替換字串。
- `docs/WAGONG_LEGACY_NAME_AUDIT.md` 已記錄上游 Repository ID 不得改成不存在的 Wa-Gong Repository ID，但介面模型名稱仍有誤導。
- 使用者於本次工作階段指出畫面名稱問題，要求移除或恢復原名，並要求先記錄 Issue。

## 修正決策與範圍

優先恢復第三方模型原名 `VoiceInk Refine V1`，並清楚呈現來源。理由是讓使用者能辨識實際使用的模型，避免把 App 品牌與模型開發者混為一談。否決繼續以 `Wa-Gong Refine V1` 作為第三方模型的顯示名稱。

若後續決定移除整項模型功能，須先確認影響範圍；本 Issue 不授權刪除下載模型、使用者偏好或其他資料。

只修正來源標示所需的介面、說明與相容處理，不為了文案整理而重新命名內部型別、移動資料目錄或變更 Bundle ID。
