聲筆 Wa-Gong 1.0.0

  • 新增 OpenAI 語音轉錄，預設使用 gpt-4o-mini-transcribe，並支援其他 OpenAI 轉錄模型。
  • 完成 Gemini 文字整理流程，預設保留來源語言並輸出台灣繁體中文。
  • 新增提示詞管理介面，並整理重複的內建提示詞。
  • 錄音浮窗預設移至螢幕上方，可在設定中切換上方或下方。
  • 轉錄與潤飾狀態改為繁體中文，並沿用 App 的語言設定。
  • 加強外部 Request 的目的地與資料類型提示，讓雲端資料流更透明。

使用 OpenAI、Gemini 或其他雲端服務前，請先在 App 中設定自己的 API Key。雲端服務可能依供應商方案產生費用。
